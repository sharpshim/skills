# 변경 기록

## 0.3.0
- references/sources.md를 신설. 출처를 4등급으로 나누고, 명령어와 설정값은 1등급 공식 문서에서만
  가져오도록 함. Claude Code, Codex CLI, Gemini CLI의 문서 색인과 자주 확인하는 페이지를 수록.
- SKILL.md 2단계를 "가능하다면 검색"에서 범위가 정해진 조회로 교체. 최종 제안을 고른 뒤에만,
  제안에 들어갈 명령어와 설정값만, 제안당 1회·전체 3회 이내로 조회하고, 가능하면 서브에이전트에 맡김.
  조회하지 못한 명령어에는 확인하지 못했다고 표시함.
- 영역별 실제 사례는 검색어 틀로 조회하고 「외부 사례」로 구분해서 표시하도록 함.
- 사용자에게 제시하는 URL을 references 파일에 적힌 주소와 이번 세션에서 조회에 성공한 주소로
  제한. 기억에 의존해 쓴 링크가 존재하지 않을 수 있다는 문제를 막기 위함.

## 0.2.0
- 진단 영역에 "토큰 사용량"을 추가. 세션에서 컨텍스트를 크게 차지한 호출을 지목하고, 같은 정보를
  더 적은 토큰으로 얻는 명령을 제시하도록 함. 지목할 호출이 없으면 다루지 않는다는 제한을 함께 둠.
- 기법 카탈로그에 "토큰 절감 기법" 절을 신설. 읽는 범위 좁히기, 도구 출력 잘라내기, 중간 산출물은
  파일로 보내기, 조사는 서브에이전트에 맡기기, 캐시를 깨지 않는 순서로 작업하기, 모델과 노력 수준
  낮추기를 수록.
- 제안 본문에서 기법을 처음 언급할 때 "how-pros-work 기법 카탈로그의 「기법 이름」"처럼 출처를
  밝히도록 지시를 추가. 그냥 "카탈로그"라고만 적으면 무엇을 가리키는지 알 수 없다는 의견을 반영.
