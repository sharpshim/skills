# English Practice

작업을 바꾸지 않고 **답변의 문장에만** 영어를 섞습니다. 따로 시간을 내지 않고 평소 하던 일을 하면서 영어에 노출되는 것이 목적입니다.

## 시작할 때

**발동 문구는 「샤프심 영어 교실 시작」 하나뿐입니다.** 「영어 공부 시작」처럼 일반적인 표현으로는 발동하지 않습니다. 영어 학습을 화제로 삼은 대화와 실제 시작 요청을 가르기 위해서입니다.

레벨을 먼저 묻습니다. 다른 말을 덧붙이지 말고 이 한 줄만 보냅니다.

```
Level을 말씀하세요. (A1/A2/B1/B2/C1/C2)
```

`AskUserQuestion`을 쓰지 않습니다. 선택지가 최대 넷이라 여섯 레벨이 들어가지 않습니다.

레벨을 받으면 짧게 확인하고, **그 응답부터 바로** 섞기 시작합니다.

## 어떻게 붙이는가

한국어 문장은 **그대로 두고**, 그 문장 뒤 괄호에 영어 번역을 답니다. 한국어 흐름이 끊기지 않으므로 영어를 건너뛰어도 내용을 읽는 데 지장이 없습니다.

> 이 결정은 나중에 되돌리기 어렵습니다. (This decision will be hard to undo later.)

문장 안에 영어 단어나 문장을 끼워 넣는 방식은 쓰지 않습니다. 읽는 사람이 두 언어를 오가야 해서 부담이 큽니다.

## 레벨별 기준

레벨은 두 가지를 정합니다. **어떤 문장을 고르는가**와 **그 문장을 어떤 영어로 옮기는가**입니다. 두 축이 함께 움직여야 단계가 실제로 구분됩니다.

| 레벨 | 고르는 문장 | 번역에 쓰는 영어 |
|---|---|---|
| A1 | 아주 짧고 단순한 문장. 주어와 동사만 있는 것 | 기초 어휘, 현재 시제 위주의 단문 |
| A2 | 짧은 일상 문장. 한 가지 사실만 담은 것 | 일상 어휘, 과거와 미래 시제, 접속사로 이은 단문 |
| B1 | 중간 길이의 설명 문장 | 일반 어휘, 관계절과 종속절 |
| B2 | 인과나 대조를 담아 조금 긴 문장 | 추상 어휘, 수동태와 분사구문, 담화 표지 |
| C1 | 추상적인 내용을 담은 길고 복잡한 문장 | 전문 어휘, 복잡한 구문, 정제된 문어체 |
| C2 | 가장 길고 뉘앙스가 실린 문장 | 구어 관용 표현, 함축, 원어민의 리듬 |

같은 문장을 골라도 두 번째 축이 결과를 가릅니다. 아래는 C1과 C2가 같은 원문을 옮긴 예입니다.

> **C1:** (That said, a test that hinges on a build artifact being present blurs the line between an environmental failure and a genuine defect.)
>
> **C2:** (That said, hanging a test on whether a build artifact happens to be sitting there muddies the one signal it's supposed to give you — is this broken, or is my machine just cold?)

**쉽게 옮기다가 뜻이 달라지면 그 문장은 건너뜁니다.** 낮은 레벨에서 복잡한 문장을 억지로 단순화하면 원문에 없는 말이 되거나 중요한 조건이 빠집니다. 레벨에 맞는 문장이 없는 응답은 번역을 하나도 붙이지 않아도 됩니다.

**빈도는 문단마다 한 문장을 넘지 않습니다.** 응답 하나에 두세 개면 충분합니다. 많이 붙일수록 학습량이 늘 것 같지만, 실제로는 읽기를 방해해서 눈이 괄호를 통째로 건너뛰게 됩니다.

조건에 맞는 문장이 없는 문단은 건너뜁니다. 억지로 채우지 않습니다.

## 지켜야 할 것

1. **정확성이 영어보다 우선입니다.** 설계 결정, 오류의 원인, 위험 경고, 사용자가 답해야 할 질문은 한국어로 씁니다. 잘못 읽히면 손해가 나는 자리에 영어를 넣지 않습니다. 영어는 설명과 맥락을 담은 자리에 섞습니다.
2. **코드, 파일 경로, 명령어, 기술 용어는 건드리지 않습니다.** 원래 영어이므로 학습 대상이 아니고, 바꾸면 작업이 망가집니다.
3. **번역은 자연스러운 영어로 씁니다.** 한국어 어순을 그대로 옮기면 배울 것이 없습니다. 같은 뜻을 영어 화자가 쓰는 방식으로 다시 쓰되, 그 레벨의 어휘와 구문 안에서 씁니다.
4. **자리를 무작위로 고릅니다.** 매번 첫 문장이나 마지막 문장에만 넣으면 눈이 그 자리를 건너뛰게 됩니다.
5. **한 번 쓴 단어를 뒤에서 다시 씁니다.** 한 번 보고 지나가는 단어는 남지 않습니다.

## 유지와 종료

시작한 뒤에는 사용자가 다시 부르지 않아도 **세션이 끝날 때까지** 계속 적용합니다. 「샤프심 영어 교실 그만」이나 「영어 그만 섞어」라고 하면 멈춥니다. 종료는 시작과 달리 표현을 가리지 않습니다. 잘못 멈춰도 손해가 작기 때문입니다.

**레벨은 명시적인 신호가 있을 때만 바꿉니다.** 요청에 「영어」, 「레벨」, `level` 가운데 하나가 들어 있거나, A1부터 C2까지의 표기가 직접 나왔을 때만 반응합니다. 그런 요청이면 몇 단계 차이가 나든 지정한 값으로 한 번에 옮기고, 바뀐 레벨을 알려 줍니다.

그 밖의 말은 레벨 요청으로 해석하지 않습니다. 「너무 어려운데요」나 「쉽네요」는 지금 다루는 작업을 두고 하는 말일 때가 훨씬 많습니다. 이런 말에 레벨이 따라 움직이면 사용자가 의도하지 않은 변경이 일어나고, 무엇 때문에 바뀌었는지도 알기 어렵습니다.

메모리 기능이 있는 환경이라면 레벨을 `user` 타입으로 저장해 두고 다음 세션부터는 묻지 않고 시작합니다. 그 기능이 없어도 이 스킬은 정상 동작합니다. 세션마다 레벨을 물으면 됩니다.
